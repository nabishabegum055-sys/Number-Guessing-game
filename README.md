# 🎯 Number Guessing Game & Word Counter

A beginner-friendly Python command-line application developed as part of my **InternCircle Python Internship – Task 2**.

## 📌 Project Description

This project combines a **Number Guessing Game** and a **Word Counter** into one menu-driven Python application.

The Number Guessing Game generates a random number between 1 and 100 and allows the user to guess it. The program provides hints, counts the number of attempts, and calculates a score.

The Word Counter reads a text file and analyzes the words in the file by calculating the total word count and word frequency.

## ✨ Features

### 🎲 Number Guessing Game
- Generates a random number between 1 and 100
- Accepts user guesses
- Provides "Too High" and "Too Low" hints
- Counts the number of attempts
- Calculates a score
- Handles invalid input

### 📄 Word Counter
- Reads text from a file
- Counts total words
- Calculates word frequency
- Displays the most frequently used words
- Handles missing files

## 🛠️ Technologies Used

- Python 3
- Random Module
- Collections Module
- File Handling
- Functions
- While Loops
- Conditional Statements
- Exception Handling
- String Manipulation
